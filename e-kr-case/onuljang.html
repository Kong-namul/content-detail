새로운 장보기의 시작, 오늘장 앱 리뉴얼

클라이언트
(주)오늘장
런칭
2026.03
범위
Mobile App, Renewal, UX/UI
플랫폼
iOS, Android
KEY VISUAL · 16:9

장바구니를 채우는 일이 아니라, 오늘 저녁상을 떠올리는 일에서 장보기가 시작되도록 오늘장의 첫 화면부터 결제까지 모든 흐름을 새로 그렸습니다.

GOAL BANNER · 21:9

PROJECT GOAL

찾는 앱에서 둘러보는 앱으로

오늘장은 30분 안에 도착하는 신선식품 배송으로 빠르게 성장했지만, 앱은 필요한 물건을 검색해 담고 나가는 도구에 머물러 있었습니다. 이번 리뉴얼은 사용자가 앱 안에서 오래 머물며 새로운 식재료와 레시피를 발견하고, 다음 주에도 다시 찾아오게 만드는 것을 목표로 삼았습니다.

POINT 01

발견하는 장보기

검색창보다 먼저 영감을 건넵니다

홈 화면을 제철 재료와 오늘의 식탁 제안으로 채우고, 레시피에서 필요한 재료를 한 번에 담을 수 있도록 했습니다. 무엇을 살지 정하지 못한 사용자도 몇 번의 스크롤만으로 오늘 먹을 한 끼를 정할 수 있습니다.

HOME DISCOVERY · 16:9
POINT 02

30분 배송의 신뢰

기다리는 시간을 눈에 보이게 합니다

주문 직후부터 문 앞에 도착할 때까지 포장, 출발, 근접 단계를 하나의 타임라인으로 보여줍니다. 대체 상품이 생기면 사진과 함께 먼저 알리고 선택권을 주어, 빠르다는 약속이 믿을 수 있다는 경험으로 이어지게 했습니다.

DELIVERY TRACKING · 16:9
POINT 03

다시 찾는 단골

자주 사는 물건이 먼저 나옵니다

구매 이력을 바탕으로 자주 사는 품목을 모은 단골 칸을 만들고, 다 먹었을 시기에 맞춰 다시 담기를 권합니다. 단골 혜택은 복잡한 등급표 대신 장바구니 안의 작은 안내로 풀어 부담 없이 쌓이도록 설계했습니다.

REPEAT ORDER · 16:9

DESIGN CONCEPT

신선함이 화면에서 먼저 느껴지도록

시장 좌판 앞에 선 것처럼 재료가 가장 먼저 눈에 들어오는 화면을 지향했습니다. 키워드와 색, 아이콘이라는 세 가지 디자인 언어를 정해 홈에서 결제까지 앱 전체의 인상을 하나로 묶었습니다.

KEYWORD

신선함이 보이는 화면

장식을 덜어내고 사진과 여백에 자리를 내주었습니다. 상품 이미지는 배경 없이 크게 잘라 쓰고, 입고 시각과 산지를 상품 이름 바로 옆에 두어 신선도를 글로도 확인할 수 있게 했습니다.

KEYWORD VISUAL · 16:9

COLOR SYSTEM

채소 색에서 가져온 6색

시금치의 초록, 당근의 주황, 가지의 보라처럼 장바구니에 담기는 재료의 색에서 여섯 가지를 골랐습니다. 색은 카테고리를 구분하는 데에만 쓰고, 버튼과 본문은 차분한 무채색으로 두어 상품이 돋보이게 했습니다.

COLOR PALETTE · 16:9

ICON STYLE

손에 잡히는 둥근 선

끝이 둥근 두꺼운 선으로 아이콘 120여 종을 새로 그렸습니다. 손가락으로 누르기 좋은 크기와 부드러운 윤곽을 기준으로 삼아, 작은 화면에서도 모양이 또렷하고 친근하게 읽히도록 다듬었습니다.

ICON SET · 16:9

PROCESS 01

장바구니는 한 손으로 끝나야 합니다

퇴근길 지하철이나 양손이 바쁜 주방에서도 쓰일 수 있도록 주요 동작을 화면 아래쪽 엄지 영역에 모았습니다. 수량 조절과 담기, 결제 진입까지 한 손 조작으로 이어지는지 사용성 테스트로 확인하며 버튼 크기와 간격을 조정했습니다.

ONE-HAND UI · 16:9

PROCESS 02

품절도 친절하게 안내합니다

신선식품은 품절이 잦다는 점을 약점으로 두지 않고 안내의 기회로 바꾸었습니다. 품절 상품 옆에 비슷한 재료와 다음 입고 시간을 함께 보여주고, 알림을 신청하면 입고 즉시 담아 둘 수 있도록 흐름을 짧게 만들었습니다.

SOLD OUT FLOW · 16:9

PROCESS 03

작은 움직임으로 기쁨을 더했습니다

상품을 담으면 장바구니로 가볍게 날아가고, 주문이 끝나면 배달 상자가 열리는 짧은 모션을 넣었습니다. 모션은 0.4초 안에 마무리되도록 하여 속도를 해치지 않으면서도 장보기가 즐거운 일처럼 느껴지게 했습니다.
